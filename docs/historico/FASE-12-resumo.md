# Fase 12 — resumo

O Licas saiu dos Projetos e passou a ser a primeira entrada da Experiência, porque é
trabalho pago para um cliente e não um projeto pessoal. As competências subiram para
logo a seguir ao resumo, que é onde um recrutador olha primeiro.

A experiência passou a pontos que começam por um verbo — "Construí", "Apliquei" — para
quem lê só o início de cada linha ver o que fizeste; os projetos ficaram em frases
corridas. O rótulo "Programador de aplicações" saiu, e todo o texto antigo ficou
guardado com a razão.

Não encontrei nenhum erro de ortografia. Os dois PDF continuam a caber numa página, mas
agora sobram só uns 9 mm, o que dá para mais duas linhas, não mais. Nada foi publicado.
